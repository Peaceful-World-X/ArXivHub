# Icon Sources

Icons identify their respective third-party platforms; trademarks belong to their owners.
Retrieved on 2026-09-27. Files are served locally to avoid cross-origin failures.
OSF icons come from each provider's public API assets, not the shared OSF favicon.
Where direct downloads are blocked, the original site's favicon is retrieved from Google's favicon cache.
AgriRxiv uses the icon of its CABI Digital Library host.
